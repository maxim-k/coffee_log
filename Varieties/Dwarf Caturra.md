# Dwarf Caturra

No source names a distinct variety called Dwarf Caturra. WCR already describes Caturra as dwarf or compact, so the name is most likely a seller's label for Caturra. Two sources say that Venecia trees at Hacienda Sonora, where S&W's lot comes from, look like a dwarf Caturra, so the lot might also be Venecia.

Source: [World Coffee Research, Caturra](https://varieties.worldcoffeeresearch.org/varieties/caturra).
