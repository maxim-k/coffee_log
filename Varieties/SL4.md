# SL4

Named as a parent in the [[WCR_Coffee_Varieties_Catalog.pdf|World Coffee Research, Coffee Varieties Catalog]] (2025), which has no entry for it.

No group: marker tests find no introgression in SL4, but no source places it in a Bourbon or Typica subgroup. Source: [Gichimu and Gichuru](https://repository.embuni.ac.ke/items/62683107-3b0e-421b-8640-b8b7c2426e14).
