# Sidra

An Ecuadorian variety. A genotyping study matched Sidra plants to a core Ethiopian group in RD2 Vision's reference database, which fits a selected Ethiopian landrace. The same study found Batian among plants grown from seed sold as Sidra, so a farm's "Sidra" can be a mix.

Source: [Tapia-Armijos et al., 2026](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2026.1868034/full).
