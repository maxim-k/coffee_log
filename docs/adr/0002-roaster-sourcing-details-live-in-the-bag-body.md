# Roaster sourcing details live in the Bag body

A Bag keeps as properties only the fields worth filtering on: what I bought,
and the coffee's origin, variety, process, and taste. The sourcing details some
roasters publish (importer, harvest, prices, contract and release dates, lot
volume, accolades) go in the note body as text copied from the roaster. Few
roasters publish them, each words them differently, and they would double the
property list. Bases can't filter on body text, which is acceptable until I
normalize these details.
